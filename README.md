# php-oop-practice

## 概要

PHPのオブジェクト指向を使って、3人のユーザー情報を表示するプログラムを作成しました。

ユーザーの名前と年齢を表示し、18歳以上かどうかを判定する機能を実装しています。

## 使用技術
- PHP 8.2
- Docker
- HTML

## 学んだこと

- クラス、コンストラクタ、プロパティ、メソッドの基本的な使い方。
- 複数のオブジェクトを配列に格納し、foreachで順番に処理する方法。
- プロパティからデータを取得する方法と、メソッドを呼び出して処理する方法の違い。

特に、最初はプロパティとメソッドの使い分けが難しかったですが、実際にコードを書き直すことで、それぞれの役割を理解できました。

## 動作確認

Dockerを起動して、ブラウザでuser.phpにアクセスしました。

3人の自己紹介が表示され、それぞれの年齢に応じて成人・未成年が正しく判定されることを確認しました。
